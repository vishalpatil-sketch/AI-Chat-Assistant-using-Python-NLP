# AI Chat Assistant using Python + NLP

An end-to-end NLP-powered AI Chat Assistant featuring text preprocessing, intent classification, multi-turn context tracking, interactive Streamlit GUI, and optional Speech-to-Text/Text-to-Speech integration.

## Features
- **NLP Preprocessing Pipeline**: Tokenization, lowercasing, punctuation stripping, and word lemmatization via NLTK.
- **Intent Recognition & Multi-turn Context**: State tracking across user sessions using custom intent filtering.
- **Web-based GUI**: Interactive chat interface powered by Streamlit.
- **Voice Capabilities**: Optional voice input via SpeechRecognition and speech output via `pyttsx3`.
